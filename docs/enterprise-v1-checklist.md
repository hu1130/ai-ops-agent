- [ ] HTTPS 域名和证书已配置

- [ ] SMTP 或其他告警渠道测试通过
- [ ] 外部 dead-man heartbeat 地址已配置
- [ ] DeepSeek Key 已放入受限环境文件
- [ ] 需要 AI 修复的仓库已检出并配置最小 Git 权限

最后一组是客户环境验收项，不能写死在产品代码或仓库中。
